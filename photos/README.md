# 画廊图片目录 (`photos/`)

将你要展示的照片或实况视频放入此文件夹，然后在根目录的 `gallery.config.js` 中添加或修改条目即可。

## 推荐格式与尺寸

- **静态照片**：推荐 `.webp` 或 `.jpg`（宽度 `1200px ~ 1920px` 即可，兼顾清晰度与加载速度）。
- **实况照片（Live Photo）**：准备一张封面静态图（如 `moment-01.jpg`）和一段 `1.5 ~ 3` 秒的短视频（如 `moment-01.mp4`），在 `gallery.config.js` 中同时填写 `image` 与 `liveVideo` 字段，卡片会自动显示 `LIVE` 标识，支持悬停预览，也可在大图中点击播放。仅设置 `live: true` 不会把静态照片标为实况。

画廊提供「拍立得」与「胶卷」两种模式。拍立得使用对齐的等尺寸双栏网格，手机上显示单栏。胶卷为自动匀速循环滚动的连续横向长条，桌面每帧宽 400px，手机每帧最大 300px、随窄屏收缩；所有照片统一使用 3:2 图片框和固定高度说明区。无需手动按钮控制，同时仍支持触控滑动、触控板、鼠标滚轮与鼠标拖动自由拨动；点击胶卷中的任意照片会直接放大该照片（打开大图时暂停自动滚动，关闭后继续），拖动不会误触放大。

照片说明和拍摄参数在点击大图后展示；大图窗口与图片显示区域尺寸固定，缩略图单独保留一行，不因照片数量变化而跳动。顶部状态栏可通过 `nowStatus.enabled` 开启，默认收起。画廊 slogan 通过 `subtitle` 修改。
