# 画廊图片目录 (`photos/`)

将你要展示的照片或实况视频放入此文件夹，然后在根目录的 `gallery.config.js` 中添加或修改条目即可。

## 推荐格式与尺寸

- **静态照片**：推荐 `.webp` 或 `.jpg`（宽度 `1200px ~ 1920px` 即可，兼顾清晰度与加载速度）。
- **实况照片（Live Photo）**：准备一张封面静态图（如 `moment-01.jpg`）和一段 `1.5 ~ 3` 秒的短视频（如 `moment-01.mp4`），在 `gallery.config.js` 中同时填写 `image` 与 `liveVideo` 字段，卡片会自动显示 `LIVE` 标识，支持悬停预览，也可在大图中点击播放。仅设置 `live: true` 不会把静态照片标为实况。

画册模式使用错落的双栏，手机上显示单栏；拍立得模式使用白色相纸边框。照片说明和拍摄参数在点击大图后展示，大图按原比例完整显示。顶部状态栏可通过 `nowStatus.enabled` 开启，默认收起。
