# 画廊图片目录 (`photos/`)

将你要展示的照片或实况视频放入此文件夹，然后在根目录的 `gallery.config.js` 中添加或修改条目即可。

## 推荐格式与尺寸

- **静态照片**：推荐 `.webp` 或 `.jpg`（宽度 `1200px ~ 1920px` 即可，兼顾清晰度与加载速度）。
- **实况照片（Live Photo）**：准备一张封面静态图（如 `moment-01.jpg`）和一段 `1.5 ~ 3` 秒的短视频（如 `moment-01.mp4`），在 `gallery.config.js` 中同时填写 `image` 与 `liveVideo` 字段，胶片边码与灯箱顶部会自动显示实况标识，支持悬停预览和灯箱内点击播放。仅设置 `live: true` 不会把静态照片标为实况。
- **多图组照**：通过 `images` 数组填写多张图片路径，胶片边码会自动标出张数，进入灯箱后可通过右下角缩略图或键盘 `↑ / ↓` 键切换同组照片。

画廊采用暗房 35mm 全宽横向胶卷模式，默认匀速无限循环滚动，悬停或聚焦胶卷时自动停稳，并在系统开启“减少动态效果”时保持静止；无需额外按钮控制，同时支持触控滑动、鼠标滚轮、鼠标拖动与键盘方向键。点击任意画面进入暗房全屏灯箱，展示标题、文字记录、日期、地点、拍摄参数与同组缩略图。顶部状态栏可通过 `nowStatus.enabled` 开启，默认收起。画廊标题与副标题通过 `title` 和 `subtitle` 修改。
